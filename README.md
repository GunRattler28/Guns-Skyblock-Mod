# Gun's Skyblock Mod
## What does it do?

Gun's Skyblock Mod is a fabric mod for minecraft that is designed to help make life a bit easier when playing skyblock

## Requirements
- Minecraft Java Edition Verision 26.2
- Fabric Loader
- Fabric API 0.154.0+26.2
- JAVA 21+

## Features
- Price of items (insta sell and insta buy for bazaar items. lbin for ah items. Hold shift to find price of all items in the slot. Automatically on)
- Slot locking (tap 'L' while hovering over a slot / item to lock it. Locking a slot stops you from moving the item inside it and stops you from dropping the item)
- Custom scoreboard (Shows everything default scoreboard shows and more. Adds colour and life. Automatically on)
